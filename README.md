## English

### What is this?

A comprehensive decision-making skill with **61 scientific frameworks** organized into three categories:

| Category | Count | Examples |
|----------|-------|----------|
| 🏢 Business | 27 | McKinsey 7S, Porter's 5 Forces, SWOT-TOWS, Blue Ocean, First Principles, Game Theory |
| 🧠 Psychology | 9 | CBT, ACT, DBT, Mindfulness, Self-Determination Theory |
| 🔧 Mental Models | 25+ | 5 Whys, Cognitive Bias, Design Thinking, TRIZ, Nudge Theory |

### How it works

1. **Auto-detect decision type** — opportunity, choice, planning, diagnosis, crisis, or value conflict
2. **Select frameworks** — automatically picks relevant frameworks based on your situation
3. **Analyze with each framework** — structured analysis with evidence
4. **Resolve conflicts** — when frameworks disagree, uses conflict resolution rules
5. **Output recommendation** — ✅Do / ❌Don't / ⚠️Conditional, with confidence score (⭐1-5)

### Features

- **Quick mode** (<2 min) for simple decisions
- **Standard report** for complex decisions
- **Value conflict template** for ethical dilemmas
- **Conflict resolution** when frameworks disagree
- **Confidence scoring** — know how certain the recommendation is

### Installation

```bash
git clone https://github.com/beyond06120925/decision-advisor.git
cp -r decision-advisor ~/.claude/skills/decision
```

### Usage

Just talk to your AI assistant:

- "Should I quit my job to start a business?"
- "Help me decide between React and Vue"
- "Analyze whether I should invest in this project"
- "I'm torn between two offers, help me decide"
