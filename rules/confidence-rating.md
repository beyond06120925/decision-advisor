# 置信度评估

每个结论必须标注置信度，让用户知道结论有多可靠。

---

## 评分标准

| 置信度 | 条件 | 说明 |
|--------|------|------|
| ⭐⭐⭐⭐⭐（5/5） | 4-5个框架指向同一结论 | 高置信度，可以坚定执行 |
| ⭐⭐⭐⭐（4/5） | 3个框架指向同一结论 | 较高置信度，可以执行 |
| ⭐⭐⭐（3/5） | 框架有分歧但主要结论一致 | 中置信度，谨慎执行 |
| ⭐⭐（2/5） | 框架严重冲突 | 低置信度，需要更多信息 |
| ⭐（1/5） | 无法形成结论 | 极低置信度，暂停决策 |

---

## 置信度来源

置信度来自以下方面：

### 1. 框架一致性
- 多少个框架指向同一结论？
- 这些框架是从不同角度分析的吗？

### 2. 数据质量
- 信息是否充分？
- 数据是否可靠？

### 3. 逻辑一致性
- 推理是否自洽？
- 有没有逻辑漏洞？

### 4. 经验验证
- 这个框架历史上准不准？
- 有没有类似案例支撑？

---

## 输出格式

```
**置信度**：⭐⭐⭐⭐⭐（5/5）
├─ 高置信度（4-5星）：X个框架指向同一结论
├─ 中置信度（3星）：框架有分歧但主要结论一致
└─ 低置信度（1-2星）：框架严重冲突，需更多信息
```

---

## 注意事项

1. **不要虚高置信度** — 如果只有1个框架支撑，最多3星
2. **不要虚低置信度** — 如果多个框架一致，应该给高分
3. **说明来源** — 置信度必须有依据，不能凭感觉
4. **动态调整** — 获得新信息后，置信度可能变化
