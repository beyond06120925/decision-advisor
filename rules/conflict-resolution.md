# 框架冲突解决

当多个框架结论冲突时，按以下决策树处理。

---

## 决策树

```
发现框架冲突时，按以下顺序处理：

Step 1: 检查层级优先级
   │
   ├── 有没有Level 1（全局必用）框架的结论？
   │   └── 有 → Level 1结论优先
   │
   └── 有没有Level 2（类型必选）框架的结论？
       └── 有 → Level 2结论优先于Level 3
   │
   ▼
Step 2: 检查适用性匹配度
   │
   ├── 哪个框架的"适用范围"更匹配当前问题？
   │   └── 更匹配的优先
   │
   └── 都差不多 → 进入Step 3
   │
   ▼
Step 3: 置信度打分
   │
   ├── 给每个冲突框架打分（1-5分）
   │   ├── 数据质量：信息是否充分？（1-5）
   │   ├── 逻辑一致性：推理是否自洽？（1-5）
   │   └── 经验验证：历史上这个框架准不准？（1-5）
   │
   └── 取最高分的结论
   │
   ▼
Step 4: 仍然冲突 → 告知用户
   │
   └── 明确告诉用户：
       "框架A说X，框架B说Y，原因是[具体原因]"
       "建议相信框架A，因为[理由]"
       "你选择哪个？"
```

---

## 层次区分规则

同一类问题的不同层次：

| 层次 | 框架 | 说明 |
|------|------|------|
| 情绪层 | 正念、情绪粒度、DBT | 感受管理 |
| 认知层 | CBT、卡尼曼前景理论 | 想法偏差 |
| 心理层 | SDT、马斯洛、心理资本 | 动机需求 |
| 系统层 | 塔勒布反脆弱 | 结构属性 |
| 线性连锁 | 巴菲特第二序 | A→B→C |
| 非线性回路 | 系统动力学 | A→B→A |

---

## 角度区分规则

同一现象的不同角度：

| 现象 | 角度 | 框架 |
|------|------|------|
| 风险 | 心理偏差 | 卡尼曼（损失厌恶） |
| 风险 | 系统属性 | 塔勒布（凸性/脆弱） |
| 风险 | 概率计算 | 期望值计算（数学） |
| 竞争 | 静态结构 | 波特五力 |
| 竞争 | 动态策略 | 博弈论 |
| 情绪 | 想法扭曲 | CBT（认知重构） |
| 情绪 | 接纳行动 | ACT（带着情绪行动） |
| 情绪 | 暂停觉察 | 正念（不评判觉察） |
| 情绪 | 高压生存 | DBT（痛苦耐受） |
| 情绪 | 精确识别 | 情绪粒度（命名即管理） |
| 动机 | 需求层次 | 马斯洛（你现在在哪层） |
| 动机 | 内在动机 | SDT（自主+胜任+关联） |
| 动机 | 心理资源 | 心理资本（希望+效能+韧性+乐观） |

---

## 一致结论 → 置信度高

如果多个框架从不同角度都指向同一结论：
- 置信度：⭐⭐⭐⭐⭐（5/5）
- 可以更坚定地执行

---

## 矛盾结论 → 按决策树处理

1. 检查层级：哪个层级更高？
2. 检查适用性：哪个更匹配当前问题？
3. 置信度打分：哪个得分更高？
4. 告知用户：明确说明冲突和建议
